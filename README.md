# Склад — учёт товаров

Веб-приложение для учёта товаров с собственной базой данных. Работает на компьютере и телефоне через браузер.

## Возможности
- Вход по логину и паролю, роли: **администратор** и **сотрудник**
- Товары: название, артикул, категория, цена, остаток, поставщик
- Движения склада: **приход** и **расход** (остаток пересчитывается автоматически)
- История операций по каждому товару
- Обзор: количество позиций, единиц, стоимость остатка, предупреждение о заканчивающихся товарах
- Управление пользователями (только администратор)

## Запуск
1. Открыть папку `sklad-app` в терминале.
2. Один раз установить зависимости:
   ```
   npm install
   ```
3. Запустить сервер:
   ```
   npm start
   ```
4. Открыть в браузере: http://localhost:3000

## Первый вход
- Логин: **admin**
- Пароль: **admin**

⚠️ Сразу после входа смените пароль: вкладка «Пользователи» → «Сменить свой пароль».

## Доступ с телефона (в той же Wi-Fi сети)
1. Узнать IP компьютера: в PowerShell выполнить `ipconfig` и найти «IPv4-адрес» (например, `192.168.1.50`).
2. На телефоне открыть в браузере: `http://192.168.1.50:3000`

Для доступа из любой точки (не только из дома) нужен хостинг — об этом отдельно.

## Где хранятся данные
Всё в файле `data/sklad.db`. Для резервной копии достаточно скопировать папку `data`.

## Структура проекта
- `server.js` — сервер и API
- `db.js` — база данных и таблицы
- `public/` — интерфейс (HTML, CSS, JS)
- `data/` — база данных и секретный ключ (не удалять)
